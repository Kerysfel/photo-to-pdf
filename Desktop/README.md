# Приёмник PDF

Экспериментальный приёмник для Windows и macOS на .NET и Avalonia. Приложения для iPhone и Android отправляют PDF через общий QR-протокол. Автообнаружение пока не реализовано.

## Windows

### Сборка

Требуется .NET 10 SDK. Из корня репозитория:

```sh
dotnet build Desktop/PhotoToPdf.Receiver/PhotoToPdf.Receiver.csproj -c Release
dotnet run --project Desktop/Receiver.Tests/Receiver.Tests.csproj -c Release
dotnet publish Desktop/PhotoToPdf.Receiver/PhotoToPdf.Receiver.csproj -c Release -r win-x64 --self-contained true -o publish/win-x64
```

Весь каталог публикации нужен для запуска, включая библиотеки DLL. Для создания установщика нужен NSIS:

```sh
makensis -DPUBLISH_DIR=/абсолютный/путь/publish/win-x64 -DOUTPUT_FILE=/абсолютный/путь/PhotoToPDF-Receiver-Setup.exe -DICON_FILE=/абсолютный/путь/Desktop/PhotoToPdf.Receiver/Assets/AppIcon.ico Desktop/Installer/receiver.nsi
```

Установщик не подписан и ещё не проверен на Windows; перед выпуском необходимы проверка установки и удаления и решение о подписи. Windows может показать предупреждение при запуске неподписанной программы. При запросе сетевого экрана следует разрешать доступ только в доверенных частных сетях.

Откройте приём, выберите сетевой адрес, отсканируйте QR-код совместимым клиентом и подтвердите получение файла. QR-код — секретное одноразовое приглашение: его нельзя публиковать или показывать посторонним. Сессия принимает одно подключение и действует не дольше 10 минут. Для нового подключения требуется новый QR-код. Максимальный размер PDF — 2 ГиБ.

Протокол находится в [PROTOCOL.md](PROTOCOL.md) и ещё не прошёл независимый аудит.

В Windows при запуске приёмник проверяет GitHub Releases на наличие новой Windows-версии. Для проверки и загрузки нужен интернет; PDF при этом никуда не отправляются. Установка начинается только по нажатию кнопки. Приёмник сверяет размер и SHA-256 с данными GitHub и сохраняет отметку загрузки из интернета для Windows. Это не заменяет цифровую подпись издателя. Временные установщики удаляются при последующих запусках приложения, если они уже не используются.

Выбранная папка сохранения запоминается в настройках текущего пользователя. Удаление приёмника не удаляет настройки и полученные PDF. Windows-установщик создаёт ярлыки на рабочем столе и в меню «Пуск».

## macOS

Для macOS 14 и новее есть отдельные образы для Apple Silicon и Intel. Откройте DMG и перетащите приёмник в «Программы». При запросе разрешите ему доступ к локальной сети. В Mac-версии проверки обновлений пока нет; новые версии публикуются в GitHub Releases.

Эти предварительные сборки имеют только локальную ad hoc подпись и не нотариально заверены Apple. Gatekeeper может не разрешить их открытие после загрузки; для полноценного распространения потребуется Developer ID и нотариализация. Сборка Intel не проверена на физическом Intel Mac.

Собрать образы на Mac с Xcode и .NET 10 SDK:

```sh
Desktop/macOS/build.sh osx-arm64
Desktop/macOS/build.sh osx-x64
```

При необходимости можно задать путь к SDK через переменную `DOTNET`. Образы создаются в `Desktop/dist/`. Скрипт использует ad hoc подпись; для нотариализованного распространения необходима отдельная процедура подписи Developer ID.
