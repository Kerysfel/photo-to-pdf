# Фото → PDF

Минимальное приложение для iPhone (iOS 16+). Съёмка страниц подряд без закрытия камеры после каждого снимка, импорт из «Фото», удаление и перестановка страниц, экспорт одного PDF через стандартное меню «Поделиться».

Доступна версия для iPhone и экспериментальная отправка PDF на [приёмник Windows](Desktop/README.md) по QR-коду. Установщик и передача пока не проверены вместе на физических устройствах. Android, приёмник для macOS и автообнаружение — планы развития.

Количество страниц программно не ограничено. Фотографии хранятся в Documents/Pages на iPhone, порядок — в атомарно записываемом pages.json. После перезапуска сессия восстанавливается. Один файл изображения обрабатывается за раз; не загружается массив из 200 полноразмерных фотографий. Длинная сторона сохранённого JPEG ограничена 3000 пикселями, качество 82%. PDF содержит по одному изображению на странице A4 без обрезки.

## Установка

1. Установите полный Xcode и компонент iOS, откройте `PhotoToPDF.xcodeproj`.
2. Xcode → Settings → Apple Accounts: войдите в свой Apple Account. Бесплатного Personal Team достаточно для установки на устройство.
3. В проекте выберите target PhotoToPDF → Signing & Capabilities → Automatically manage signing → свой Team. Если Bundle Identifier занят, замените его на уникальный, например `com.yourname.PhotoToPDF`.
4. Подключите разблокированный iPhone к Mac и разрешите «Доверять этому компьютеру». При запросе включите Settings → Privacy & Security → Developer Mode на iPhone и подтвердите после перезагрузки.
5. Выберите iPhone в списке устройств Xcode и нажмите Run (⌘R). Если iOS попросит доверие разработчику, подтвердите его в Settings → General → VPN & Device Management.
6. Разрешите доступ к камере. Снимите 3–5 пробных страниц, экспортируйте PDF через «Сохранить в Файлы» и проверьте порядок и читаемость, затем переходите к большой сессии.

Apple ID владельца iPhone не обязан совпадать с аккаунтом подписи в Xcode. Бесплатный provisioning profile истекает через 7 дней: для дальнейшего запуска снова установите приложение через Xcode. Не удаляйте приложение при обновлении, чтобы сохранить его локальные данные. Экспортированный в «Файлы» PDF остаётся отдельным документом. После сопряжения установка может выполняться по Wi‑Fi; кабель удобнее для первой настройки.

Официальные инструкции: [Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account), [запуск на устройстве](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices), [Wi‑Fi](https://help.apple.com/xcode/mac/current/en.lproj/dev3e2f4ee6d.html).

## Использование

- «Снимать» → «Снять страницу». Дождитесь обновления счётчика перед следующим кадром; «Готово» возвращает к списку.
- «Из фото» импортирует выбранные изображения в порядке выбора, по одному. Доступ ко всей фотобиблиотеке не запрашивается.
- Смахните строку влево для удаления. «Править» позволяет переставлять строки за ручку.
- «Собрать PDF и сохранить» создаёт PDF в Documents/Exports и открывает меню сохранения/отправки. Доступны настройки качества 100%, 75% и 50%: при 100% используется сохранённый JPEG без дополнительного сжатия, при 75% и 50% изображение уменьшается и перекодируется. Проценты не гарантируют определённый размер файла.
- «Отправить на компьютер» собирает PDF и открывает сканер QR-кода приёмника Windows. Для уже собранного PDF эта кнопка доступна в истории. Подтвердите получение на компьютере; текущий комплект сохраняется. Отправка работает напрямую по локальной сети через TLS и требует доступа к локальной сети.
- Все операции локальные, без сервера. Для загрузки фото, хранящегося только в iCloud, импорт может потребовать сеть.

Это фотокопии: автоматической коррекции перспективы, OCR и распознавания границ страниц в этой версии нет. Снимайте вертикально при хорошем освещении. Для нового комплекта нажмите корзину и подтвердите очистку всех снимков. После успешного завершения системного действия через меню «Поделиться» текущий комплект очищается автоматически; отмена меню сохраняет снимки. Системный флаг завершения не подтверждает доставку получателю. Собранные PDF остаются в «Истории»: просмотр, дата, число страниц и повторная отправка. История включает ранее собранные PDF из папки Exports. Это локальная история устройства; удаление приложения удалит её, поэтому важные PDF сохраняйте отдельно в «Файлы». Закрытие после отправки означает закрытие меню и переход к пустому комплекту; приложение остаётся открытым. Следите за свободным местом: 200+ фото и PDF могут занимать сотни мегабайт. Не удаляйте приложение до сохранения нужного PDF во внешнюю папку «Файлов».

## Проверка

Сборка без подписи на Mac с полным Xcode:

```sh
xcodebuild -project PhotoToPDF.xcodeproj -scheme PhotoToPDF -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

Обязательная проверка на устройстве: доступ к камере/отказ в разрешении, несколько последовательных кадров, закрытие и повторное открытие приложения, перестановка/удаление, экспорт и сохранение, импорт и экспорт 200+ фото. Замер памяти и реальная камера требуют iPhone; отсутствие ограничения в коде не является результатом нагрузочного теста на устройстве.
