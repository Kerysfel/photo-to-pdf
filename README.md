# Фото → PDF

Приложение для съёмки и объединения фотографий в PDF. Страницы можно переставлять и удалять, а готовые документы — просматривать в истории.

PDF можно отправить с iPhone или Android на Mac или Windows напрямую по локальной сети. Соединение шифруется с помощью TLS, а получатель проверяется по QR-коду.

[Скачать приложения и приёмник](https://github.com/Kerysfel/photo-to-pdf/releases/tag/v1.6.0-release)

## Установка на iPhone

1. Установите Xcode, откройте `PhotoToPDF.xcodeproj` и войдите в Apple Account в **Xcode → Settings → Accounts**.
2. В настройках цели **PhotoToPDF → Signing & Capabilities** включите **Automatically manage signing** и выберите свою команду. При необходимости задайте уникальный Bundle Identifier.
3. Подключите разблокированный iPhone к Mac и подтвердите доверие к компьютеру. При запросе включите на iPhone **Настройки → Конфиденциальность и безопасность → Режим разработчика**.
4. Выберите iPhone в Xcode и нажмите **Run** (`⌘R`). При запросе подтвердите доверие разработчику в **Настройки → Основные → VPN и управление устройством**.

Бесплатная подпись действует 7 дней, после чего приложение нужно снова установить через Xcode. Устанавливайте обновление поверх существующей версии, чтобы сохранить данные.
