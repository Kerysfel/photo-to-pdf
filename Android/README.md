# Фото в PDF для Android

Предварительная Android-версия: Android 8.0 и новее. Снимки и PDF хранятся в закрытом каталоге приложения. Удаление приложения удалит эти данные; важные PDF заранее сохраните через «Поделиться».

Доступны последовательная съёмка, импорт через системный выбор файлов, порядок и удаление страниц, восстановление комплекта, PDF A4 (100%, 75%, 50%), локальная история, удаление и просмотр страниц PDF и передача на приёмник Windows по QR-коду. Режим 100% использует сохранённый JPEG без дополнительного сжатия; 75% и 50% уменьшают и перекодируют изображения. Проценты не гарантируют размер файла. Android не подтверждает доставку получателю в системном меню «Поделиться», поэтому комплект после него сохраняется.

Передача на компьютер прямая по локальной сети: сертификат приёмника сверяется с отпечатком в QR-коде до передачи секрета и PDF. Подробности и ограничения — в [описании протокола](../Desktop/PROTOCOL.md). Протокол не проходил независимый аудит.

## Сборка

Нужны JDK 17 и Android SDK Platform 35. Из папки `Android`:

```sh
./gradlew assembleDebug
./gradlew assembleRelease
```

Debug-версия содержит изолированную диагностическую проверку и предназначена только для разработки. Release APK необходимо подписать личным ключом разработчика и проверить `apksigner verify`. Для обновления поверх уже установленной версии необходим тот же ключ. Никогда не добавляйте ключ или пароли в репозиторий; сделайте защищённую резервную копию ключа и пароля.

## Проверки

На эмуляторе Android 15 выполнены проверка восстановления 240 синтетических снимков, сборка и повторное открытие PDF во всех трёх режимах, очистка комплекта с сохранением истории, передача Android → приёмник .NET и отказ при неверном сертификате. На эмуляторе также проверены два последовательных кадра и их восстановление после запуска. Съёмку, импорт и передачу на реальных устройствах ещё необходимо проверить; нагрузочный тест на реальных 200+ фотографиях не проводился.
